# ROCKET Shield

Кросс-платформенный набор для защиты от DDoS-атак: XDP/eBPF + nftables на
Linux (реакция в ядре, <1мс), fallback на iptables для VPS без поддержки
XDP, и агенты для Windows/macOS/FreeBSD/OpenBSD через штатные файрволы этих ОС.

Ловит и объёмные атаки (SYN/UDP/ICMP flood, amplification), и
низкоинтенсивные (slowloris, low-rate HTTP flood, брутфорс) — через
адаптивный EWMA-baseline поверх фиксированных порогов.

## ⚠️ Честно про ограничения

**Это не серебряная пуля.** Защита работает в пределах пропускной
способности канала и вычислительных ресурсов сервера, на котором
установлена. Если объём атаки превышает канал сервера — трафик физически
не доходит до точки, где его можно отфильтровать, и здесь бессильна
любая локальная защита, не только эта. Для атак такого масштаба нужен
upstream-scrubbing (Cloudflare, защита на стороне хостинг-провайдера и
т.п.) — эта система с ним не конкурирует, а дополняет его на уровне
конкретного сервера.

Не используйте формулировки вида "100% защита от любых DDoS" при
описании этого инструмента кому-либо — это неточно и может ввести в
заблуждение.

## Возможности

| Слой | Что ловит | Платформа | Скорость реакции |
|---|---|---|---|
| XDP/eBPF | SYN/UDP/ICMP flood, amplification | Linux (совр. ядро) | микросекунды |
| nftables / iptables | то же + connection-rate limiting | Linux | миллисекунды |
| Suricata | сигнатуры, известные инструменты | Linux (опционально) | доли секунды |
| L7 Watcher (Python) | slowloris, low-rate flood, поведенческие аномалии | Linux/Windows/macOS/BSD | ~1-2 сек |
